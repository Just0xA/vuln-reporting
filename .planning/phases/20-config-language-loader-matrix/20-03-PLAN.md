<objective>
Deliver the delivery-matrix legibility tool (CONF-05). A standalone `scripts/generate_delivery_matrix.py` reuses the loader's resolved config and renders a matrix — deliveries × reports × schedule × filters × owner — as Markdown (default) or HTML (`--format html`), answering "who gets what, when" without opening any YAML. The matrix shows contact/group NAMES + owner at the pre-expansion granularity, never expanded recipient addresses (D-05), so it is safe to publish as a Phase 21 CI artifact.

The owner + contact-NAME columns come from the resolver's `metadata_by_delivery_name` side channel (the 4th element of `resolve_config`'s return), joined to each matrix row by delivery name. They are NOT read off the group dict — the group dict is schema-shaped and (per D-09, schema unchanged with `additionalProperties: false` at the group level) carries no `owner`/`contact` keys.

Purpose: CONF-05 is the phase's legibility deliverable and the natural first consumer / acceptance test of the resolver. It is trivial for the Phase 21 CI step to invoke.

Output: `scripts/generate_delivery_matrix.py` (new standalone script modeled on `scripts/warm_cache.py`) and `tests/test_generate_delivery_matrix.py`.
</objective>
