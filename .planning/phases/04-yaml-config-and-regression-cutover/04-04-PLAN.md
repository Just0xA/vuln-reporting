**PII guard (defensive backstop, revised D-04-08):**
The extractor never serializes column-level data anyway, but a defensive guard catches future contributors who add row-level fields by mistake. Implementation:

```python
_PII_EXACT = frozenset({
    "hostname", "ipv4", "ipv6", "fqdn", "plugin_name",
    "recast_reason", "recipient_email", "business_unit_name",
})
_PII_SUBSTRING = ("asset_name", "host_name", "ip_address")  # narrow backstop

def _is_pii_column(col: str) -> bool:
    low = str(col).lower()
    if low in _PII_EXACT:
        return True
    return any(s in low for s in _PII_SUBSTRING)
```

Rationale: a pure substring match on `name`/`address`/`email` produces too many false positives (`tag_name`, `email_panel_count`, `cell_address`). The exact-match list catches the literal sensitive column names; the narrow substring list covers common variants (`asset_name`, `host_name`, `ip_address`) without snagging benign names.

def _pdf_page_count_from_html(pdf_html: str) -> int:
    """Authoritative PDF page count via WeasyPrint byte stream.

    Renders pdf_html to bytes and counts `/Type /Page` PDF objects. The
    regex `/Type\\s*/Page\\b` matches both `/Type /Page` (per-page) AND
    `/Type /Pages` (the catalog object that lists all pages); we subtract
    1 for the catalog (verified May 7 sanity check, observation 342).

    Falls back to the HTML page-break count + 1 + 1 (the +1 for cover via
    CSS, the +1 for the final implicit page) ONLY if WeasyPrint is not
    importable — should never happen in this project (WeasyPrint is a
    pinned dependency in requirements.txt).
    """
    try:
        from weasyprint import HTML  # noqa: PLC0415
    except Exception:
        # Last-resort fallback. Note this matches the original off-by-one
        # heuristic + 1 for cover; documented as inferior in the docstring.
        return pdf_html.count('class="page-break"') + 2
    try:
        pdf_bytes = HTML(string=pdf_html).write_pdf()
    except Exception:
        return pdf_html.count('class="page-break"') + 2
    n = len(re.findall(rb'/Type\s*/Page\b', pdf_bytes))
    return max(n - 1, 0)   # subtract catalog; clamp at 0 for empty PDFs
