<objective>
Capture a structural smoke baseline from the CURRENT bespoke `management_summary`
render path AND lock the exact bespoke numerical outputs against a frozen
synthetic fixture — both committed BEFORE any migration code is written. This is
the QUAL-04 contract and D-18-10 gate 3 (structure) plus the review-approved
value-locked parity gate (review HIGH change #1, QUAL-02).

The structural baseline encodes the structural shape (section count, RAG cell
count, module presence, Excel tab names, email panel count) of today's bespoke
output so the migrated output can be diffed against it post-cutover. The value
golden locks the exact metric numbers the BESPOKE path produces against a small
deterministic synthetic parquet fixture, so Plan 04 can run the NEW modular path
against the SAME fixture and assert zero numerical drift — catching the subtle
%/rounding/edge-case drift that visual UAT misses.

D-04-05 reconciliation (review-approved, NOT a decision reversal): D-04-05
("structure locked, values NOT") governs LIVE-drifting values, which change
daily. The value golden here is locked against a FROZEN SYNTHETIC INPUT, so it is
deterministic and does not depend on live data. Locking the bespoke output of a
fixed input and asserting the migrated output of the SAME fixed input matches is
a standard regression check, not a live-value lock — these are reconcilable and
both apply. State this explicitly so it is not mistaken for reversing D-04-05.

Purpose: De-risk the highest-risk phase. The migration in Plan 04 cannot proceed
until BOTH baselines exist — a baseline captured after migration code lands is
worthless as a regression guard (RESEARCH Pitfall 6), and the bespoke path is
ATOMICALLY REMOVED at the Plan 04 cutover, so the bespoke golden values can ONLY
be captured here while the bespoke path still exists (a real sequencing
constraint, not a free add-on).
Output: `scripts/smoke_management_summary_cutover.py` + its committed structural
baseline JSON + the frozen synthetic parquet fixture + the committed bespoke
value golden JSON + the golden-capture script.
</objective>
