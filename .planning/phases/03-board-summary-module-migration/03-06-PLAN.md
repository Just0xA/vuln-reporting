**W7 — None/NaN-safe formatter contract (CLAUDE.md "Empty-data guard pattern" rule 1).**

Both the test fixture (`check_9_phase3_populated_render_methods`) and the smoke fixture (`_build_smoke_module_data`) MUST use `safe_pct(pct)` from `reports.modules.format_utils` when interpolating any metric value into `headline_value_str`. Inline f-string format specs like `f"{pct:.1f}%"` are forbidden — they crash on `None` / `NaN` and they model the wrong pattern (test/smoke code is what new contributors copy when adding new modules).

`safe_pct` returns `NO_DATA_HEADLINE` (the em-dash) for `None` / `NaN` / unparseable input and a `"{:.1f}%"`-formatted string for numeric input. It is import-safe to call inside any fixture builder.
