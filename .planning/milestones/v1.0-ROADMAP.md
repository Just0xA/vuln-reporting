## Overview

v1 established the modular pattern as the durable unit of report composition for the Vulnerability Management Reporting Suite. The `BaseModule` / `ReportComposer` infrastructure existed as brownfield code that rendered to PDF and basic Excel only — email was bare, the PDF cover was thin, and analysts had no drill-down path. v1 extended the contract with three new render hooks (email panel, analyst tabs, RAG strip entry), upgraded the composer to assemble email bodies, RAG-strip cover pages, and a paired analyst-detail companion workbook, then proved the pattern end-to-end by migrating Board Summary's four metric modules to the new contract — without regressing the recipient groups that already consume Board Summary today.

The journey: define the contract (Phase 1) → upgrade the composer (Phase 2) → migrate Board Summary against both (Phase 3) → wire YAML opt-out and confirm zero regression (Phase 4).

### Issues / Bugs Surfaced and Resolved

- **Phase 03 UAT BLOCKER (`ValueError: Cannot convert <NA> to Excel`)** at `composer.py:1153` against real Tenable data. Synthetic regression fixtures used non-null DataFrames so the bug only reproduced live. Closed by Plan 03-07 with a structural negative control (RED→GREEN commit boundary). Bonus surface: tzinfo strip needed to avoid second BLOCKER on tz-aware datetimes.
- **Phase 03 UAT major (RAG strip on separate page + 3+1 wrap)**. Cover layout regression after the unified-cover collapse in Phase 3. First fix attempt (62mm → 58mm) was insufficient because the theoretical geometry math underestimated WeasyPrint flex's phantom-space consumption by ~3×. Empirical bisect found the threshold at 56mm; pinned 55mm.
- **Plan 04-04 plan-checker iter-1 blockers**: `class="module-panel"` literal didn't exist in real rendered HTML (composer concatenates `<table role="presentation">` fragments without wrapping div); PDF page-count heuristic was off-by-1 (cover doesn't emit `<div class="page-break">`). Caught before execution; iter-2 used `role="presentation"` marker (verified) and WeasyPrint `/Type /Page` byte-stream regex (with `uncompressed_pdf=True`).
- **16 pandas-3.0 ChainedAssignmentError FutureWarnings** across 4 board modules (`scan_coverage_sla_module:395`, `board_report_utils.py:449/454/469`, `high_risk_assets_module.py:267/366/388`, `aged_vulns_assets_module.py:262/361/385`).
