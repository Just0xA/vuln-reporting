| Boundary | Description |
|----------|-------------|
| Claude tool-call → PreToolUse hook | Untrusted Bash command string crosses the hook before any Tenable fetch can run; the hook is the sole programmatic guard preventing a PII-bearing Tenable export from being initiated by an agent. |
| caller → trend_store filename | `tag_filter` (operator/group-config-derived) flows into a filesystem path; a `/../` component crosses into the filesystem. |
| module data → delivered email HTML | `data.error` and owner-label strings flow unescaped into email HTML sent to recipients. |
| caller → owner_supplemental output_dir | An output path flows into `mkdir` + PII-bearing file writes; `data/trend/` is a no-PII zone. |
