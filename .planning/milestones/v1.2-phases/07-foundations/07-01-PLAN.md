CRITICAL — git archive semantics:
- `git archive HEAD` reads from the committed tree at HEAD. It IGNORES the index and the working tree.
- An untracked or staged-but-uncommitted `.gitattributes` has NO effect on `git archive HEAD` output.
- `git add` is NOT sufficient. `--worktree-attributes` does NOT cover `export-ignore`.
- Therefore: `.gitattributes` MUST be committed (atomic commit) BEFORE running any `git archive HEAD` verify.
