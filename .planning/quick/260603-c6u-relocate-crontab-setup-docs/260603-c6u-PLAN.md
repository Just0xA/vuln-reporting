   `sudo -u vuln-reports crontab - < /opt/vuln-reporting/current/deploy/crontab.example`

     group (the fetch must complete before any group fires; e.g. 06:15 for a 07:00
     earliest group).
   - TIMING RULE B: never schedule near midnight — cache folders are named by SERVER

   modules and `python -m` only adds the CWD to sys.path; cron's default CWD is the

   ALL path occurrences in each cron line must change together — the `cd` target, the
   interpreter path, AND the `>>` log-redirect path. Cross-reference the existing
   [Relocating the install base](#relocating-the-install-base) section.

5. The cron-level `.cron.log` redirects (warm_cache.cron.log, run-due.cron.log) are
   NOT auto-rotated — only the scripts' own rotating logs are. Reference the logrotate
   snippet that ships inline in deploy/crontab.example (do not re-paste the full block;
